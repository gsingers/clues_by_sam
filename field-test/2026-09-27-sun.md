## Heuristics for a new player (this board)
- Build the differ-pair chain early. Three compound clues each yielded a pair, and the pairs then fixed column totals, parity and the edge total without being resolved.
- For "N innocents on the edges", subtract known cells and the pairs' fixed contributions first. The remainder is usually a tiny set with a count of 1.
- For "only one column has exactly k", write each column's count as number + open cells. Usually one column alone can hit k.
